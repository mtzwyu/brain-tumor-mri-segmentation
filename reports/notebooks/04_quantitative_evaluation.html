1. Bộ đo định lượng y khoa chuẩn mực (Theo Khung Tổng Quát Mục II.6 & IV)¶

  1. Dice Similarity Coefficient (DSC / F1-score): $$\text{Dice} = \frac{2|P \cap G|}{|P| + |G|} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}}$$
  2. Jaccard Index (IoU - Intersection over Union): $$\text{IoU} = \frac{|P \cap G|}{|P \cup G|} = \frac{\text{Dice}}{2 - \text{Dice}} = \frac{\text{TP}}{\text{TP} + \text{FP} + \text{FN}}$$
  3. Độ nhạy (Sensitivity / Recall): $$\text{Sensitivity} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$ (Đo lường khả năng không bỏ sót pixel u não, cực kỳ quan trọng trong sàng lọc y tế).
  4. Độ đặc hiệu (Specificity): $$\text{Specificity} = \frac{\text{TN}}{\text{TN} + \text{FP}}$$ (Đo lường khả năng không nhận nhầm mô não lành là khối u).
  5. Độ trễ tính toán (Computational Latency): Thời gian xử lý trung bình trên từng khung hình/lát cắt (ms/slice).

def predict_ws(img):
    stripped, b_mask = strip_skull(img)
    if not verify_tumor_presence(stripped, b_mask, z_thresh=2.3):
        return np.zeros_like(img)
    return segment_watershed(stripped, dist_thresh_ratio=0.4)

def predict_rg(img):
    stripped, b_mask = strip_skull(img)
    if not verify_tumor_presence(stripped, b_mask, z_thresh=2.3):
        return np.zeros_like(img)
    return segment_region_growing(stripped, tolerance=15)

# Chạy benchmark trên 20 mẫu ảnh
df_ws = run_benchmark(img_dir, mask_dir, predict_ws, method_name="Watershed (Baseline)", max_samples=20)
df_rg = run_benchmark(img_dir, mask_dir, predict_rg, method_name="Region Growing (Đối chứng)", max_samples=20)

print(f"Đã hoàn thành đánh giá {len(df_ws)} mẫu cho Watershed và {len(df_rg)} mẫu cho Region Growing.")
